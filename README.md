# 🐍 PyMaster — интерактивная обучающая платформа по Python

**PyMaster** — это учебный веб-сайт, созданный на Django, где пользователи могут:
- Проходить структурированные курсы по Python, ООП, Django, FastAPI, SQL и другим темам.
- Смотреть уроки, разделённые на слайды с плавной навигацией.
- Использовать встроенную онлайн-консоль для выполнения Python-кода прямо в браузере.
- Следить за своим прогрессом и возвращаться к пройденным материалам.

---

## Основные разделы сайта

```bash
Главная страница - приветствие и краткое описание проекта.
Курсы - список направлений (Python, ООП, Django, FastAPI, SQL, Проекты).
Уроки - каждый курс разбит на модули и уроки со слайдами и интерактивной навигацией.
Онлайн-консоль - встроенный Python-интерпретатор на JavaScript (Skulpt), позволяющий выполнять код прямо в браузере.
Профиль - страница пользователя с прогрессом по курсам (доступна после входа).
Контакты - Информация для обратной связи.
```

## 🚀 Установка и запуск проекта

### 1. Клонируй репозиторий
```bash
https://github.com/VladimirUstinov5690/python_learning.git
cd python_learning

```
## Создай и активируй виртуальное окружение

```bash
1. python -m venv venv
Windows:
2. venv\Scripts\activate
macOS / Linux:
3. source venv/bin/activate
```

## Установи зависимости

```bash
1. pip install -r requirements.txt
```

## Примените миграции базы данных

```bash
python manage.py migrate
```

## Запусти сервер разработки

```bash
python manage.py runserver
```
