Урок 2: Переменные и типы данных

Переменные в Python

Переменные — это “контейнеры” для хранения данных. В Python переменные создаются при первом присваивании значения.

Пример:

name = "Alex"
age = 25
print(name, age)

Типы данных

Python имеет несколько базовых типов данных: int (числа), float (дробные числа), str (строки), bool (логические значения).

  • int — целые числа: x = 10
  • float — дробные: pi = 3.14
  • str — строки: name = "Python"
  • bool — логические: is_active = True
